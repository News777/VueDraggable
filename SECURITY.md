# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately and responsibly.

Please use the GitHub Security Advisory feature in this repository if available, or contact the maintainers directly through the private channel provided by the project owner.

Please do not open a public issue for security vulnerabilities.

## Response Expectations

We will do our best to acknowledge the report promptly and investigate the issue as quickly as possible. We also aim to provide a reasonable remediation timeline depending on the severity of the issue.

## Supported Versions

The project currently supports the latest released version and the current main branch. Security fixes are normally backported only when practical and necessary.
